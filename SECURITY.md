# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

---

## Reporting a Security Vulnerability or Sensitive Data Issue

We take the security of this project and the sensitivity of threat intelligence data seriously.

If you discover:
1. A technical security vulnerability in the static site generator, scripts, or deployment pipeline.
2. An inadvertent disclosure of sensitive personal identifying information (PII), credentials, or harmful material in an indexed source link or milestone.

### How to Report

Please **do not** open a public GitHub issue for sensitive security vulnerabilities or PII exposures.

Instead, please report via one of the following methods:
* **GitHub Private Vulnerability Reporting:** Navigate to the repository's **Security** tab &rarr; **Advisories** &rarr; **Report a vulnerability**.
* **Direct Email:** Contact the repository maintainer directly via GitHub profile contact information.

Please include:
* A clear description of the vulnerability or data concern.
* The specific URL or file path impacted.
* Steps to reproduce or remediate the issue.

### Response Timeline
* **Initial Acknowledgment:** Within 48 hours.
* **Triage & Remediation:** We will assess and remediate critical data issues or vulnerabilities promptly, updating Git history or scrubbing sensitive data as necessary.
